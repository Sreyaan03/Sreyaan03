## 🚀 Featured Projects

### ♟️ Ensemble Chess Engine with Reinforcement Learning
> *PyTorch · RL · UCI Protocol · PGN Supervision*

A modular AI chess engine that blends **heuristic**, **ML**, **neural network**, and **TD/deep RL** evaluators using phase-aware ensemble weighting. Features tactical extraction (forks, pins, skewers), an endgame training curriculum, and **Lichess bot integration via UCI protocol**.

---

### 🐦 Capuchin Bird Call Identification & Analysis
> *TensorFlow · Keras · SciPy · Bioacoustics*

Deep audio classifier that detects and counts Capuchin bird calls in 3-minute forest recordings using **spectrograms + MFCCs**. Achieves precise call-level segmentation across complex multi-species environments.

---

### 🏏 Dynamic IPL Target Prediction Engine
> *TensorFlow · Keras · Web Scraping · Feature Engineering*

Ball-by-ball neural network that dynamically updates IPL match predictions, accounting for batting team, bowling team, and venue. Custom dataset built via scraping with **exponential decay weighting** for recent seasons.
